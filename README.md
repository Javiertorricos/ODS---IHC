## 🚀 Instrucciones para Ejecutar el Proyecto

Sigue estos pasos para clonar e iniciar el entorno de desarrollo local:

### 1. Clonar el repositorio

```bash
git clone https://github.com/Javiertorricos/ODS---IHC.git
cd ODS---IHC
```

### 2. Instalar dependencias

```bash
npm install
```

### 3. Iniciar el servidor de desarrollo

```bash
npm run dev
```

Abre tu navegador en la URL que indique la terminal (por defecto `http://localhost:5173`).

## 🌿 Estructura de Ramas

- `main`: Código estable y listo para producción.
- `desarrollo`: Rama principal para integrar características (`feature/*`).
