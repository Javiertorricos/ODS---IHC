# Frontend — Biblioteca para Estudiantes

React 19 + TypeScript + Vite + Tailwind CSS. Consume la API REST de la carpeta `../backend`.

```bash
npm install
npm run dev      # http://localhost:5173  (necesita la API en http://localhost:3001)
npm run build    # genera dist/ para producción (Netlify)
npm run lint
```

Variable de entorno: `VITE_API_URL` (ver `.env.example`). Documentación completa en `../docs` y en el `README.md` principal.
